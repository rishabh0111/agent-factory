How a specialist works

Start in 3 steps

  1. Install the core and a department

    /plugin install af-core --marketplace rishabh0111/agent-factory/plugin install af-legal --marketplace rishabh0111/agent-factory

    Swap af-legal for any department you use.

  2. Run /af-setup

    It fills in company.md with you and loads it into every session through CLAUDE.md.

  3. Ask by role

    “Have the legal specialist triage this NDA.”

Not sure which specialist? Run /af-ask. Needs Claude Code 2.1.275+. Skills that read a CRM or ticket system need its connector.
