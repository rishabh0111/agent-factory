# Leadership

Strategy and business-plan reviews, premise challenges and office hours on new ideas, run by the leadership specialist (`ceo-advisor`). Both skills interview you, so run them yourself in the main session. Reviews and design docs are saved to `docs/leadership/`.

## Installation

```
/plugin install af-leadership --marketplace rishabh0111/agent-factory
```

## Context

Run `/af-setup` (from `af-core`) first. It writes your `company.md` and loads it into every session, so these skills work from your products, customers, voice and policies.

## Skills

Skills run when your request matches, or by name. A skill marked under *Interviews you* asks you questions in rounds, so run it yourself in the main session rather than through the specialist.

<!-- skills:start -->
| Skill | What it is for | Interviews you |
|---|---|---|
| `/af-leadership:ceo-review` | Use when asked for a CEO review of a plan or business proposal, such as deciding whether to expand, hold or reduce its scope, pushing for the 10x version, or challenging its ambition before it is built. | yes |
| `/af-leadership:office-hours` | Use when a founder or builder wants to pressure-test a new startup or product idea before building it, such as whether it is worth building, YC-style office hours, or brainstorming a new idea or design direction before any code is written. | yes |
<!-- skills:end -->

## Connectors

None needed: these skills work from the plan or idea you bring.
