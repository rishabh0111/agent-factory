# User Segmentation

Cluster a product's existing users into at least 3 segments by behavior, job to be done and unmet need, not by demographics alone, and recommend where to invest. For segments of the wider market, including non-customers, use the `market-segments` skill; to turn segments into archetypes for design decisions, the `user-personas` skill.

Read `company.md` first for the product and customers; ask only for what is missing. Read the feedback, interviews, support tickets, usage logs or surveys the user provides.

## Steps

1. **Prepare the data**: inventory every source, its size and the period it covers. Done when the inventory is listed.
2. **Extract behaviors**: usage modes, frequency and depth, journeys, the tools each user combines with the product.
3. **Map needs**: jobs, desired outcomes and pains per user or response.
4. **Cluster** users into segments by similarity of behavior and need. Done when each segment has a defining behavior no other segment shares.
5. **Validate**: segments are coherent, distinct, actionable, and checked against usage or customer data when available. Flag segments the data underrepresents. Done when each segment's size is stated with its evidence.
6. **Characterize and prioritize** each segment with the fields below, with representative quotes. Note interdependencies between segments and cross-segment patterns. Name the highest-value and the highest-growth segment.

## Per segment

- **Name and overview**: descriptive name, size (number or % of the user base), one-sentence characterization.
- **Behavior**: primary use cases, frequency and depth, typical journey and touchpoints, technical sophistication, integrations and adjacent tools.
- **Jobs and motivations**: core jobs, underlying motivations, desired outcomes, context and frequency, what success looks like.
- **Needs and pains**: unmet needs, obstacles, current workarounds, severity and frequency.
- **Current product fit**: how well the product serves them, what they value most, the most frustrating gaps, churn risk.
- **Differentiated value proposition**: value that could be unlocked, improvements that would maximize fit, the messaging that would resonate.
- **Prioritization**: strategic importance (growth, revenue, vision fit), difficulty of serving them, and a recommendation: **invest**, **maintain** or **de-prioritize**.

## Output

The per-segment profiles, then a summary:

| Segment | Size | Primary job | Product fit | Value | Growth | Recommendation |
|---|---|---|---|---|---|---|
