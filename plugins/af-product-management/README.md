# Product

Product strategy and pricing, specs, roadmaps, OKRs, sprints, product discovery (ideas, assumptions, experiments, interviews), market and user research, metrics, competitive briefs and stakeholder updates, run by the product specialist (`product-specialist`).

## Installation

```
/plugin install af-product-management --marketplace rishabh0111/agent-factory
```

## Context

Run `/af-setup` (from `af-core`) first. It writes your `company.md` and loads it into every session, so these skills work from your products, customers, voice and policies.

## Skills

Skills run when your request matches, or by name. A skill marked under *Interviews you* asks you questions in rounds, so run it yourself in the main session rather than through the specialist.
