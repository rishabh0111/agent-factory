# Growth Loops

A growth loop is a closed cycle where each cohort of users brings in or reactivates the next, so acquisition compounds instead of being bought again each month. Use this when choosing which loop to build, before designing the specific mechanism (the 7 viral mechanisms in [viral-mechanisms.md](viral-mechanisms.md)) or the reward program (the main skill).

## The 5 Loop Types

| Loop | Mechanism | Example | Strength | Challenge |
|---|---|---|---|---|
| **Viral** | Normal use sends the product, or something made in it, to non-users, who sign up to view or respond | Figma files shared as links, Loom videos in emails | Fastest compounding when output is inherently shareable | Needs shareable output and a reason to share |
| **Usage** | Using the product creates something others consume (posts, templates, public pages), which draws in new users and brings existing ones back | Notion templates, Medium articles, X threads | Growth tied directly to usage | Creating has to be nearly frictionless |
| **Collaboration** | Users invite colleagues to work together inside the product | Google Docs sharing, Figma team projects, Slack channels | Deep penetration within organizations, highest retention and LTV | Only fits team-based products |
| **User-generated content** | Users discover content made by others, create their own in response, and publish it for the next wave to find | TikTok, Pinterest, YouTube trends | Content flywheel with network effects | Needs a critical mass of quality content to sustain |
| **Referral** | Users invite others in exchange for a reward or recognition | Dropbox storage bonus, Uber rider credits, PayPal signup bonus | Directly incentivized and easy to measure | The reward must stay inside unit economics |

The first four are built into the product; only the referral loop is paid for. Check the Viral Potential Spectrum before investing in any of them.

## Choosing and Designing a Loop

1. **Define the core value.** The primary action users take, the value each action creates, any network effects already present, and the friction points.
2. **Score loop fit.** Rate all five types against product type (collaborative, content, utility), how target users already share, existing network effects, and the current user base and engagement. **Done when** every loop has a fit score and a one-line reason.
3. **Design the mechanics** of the top loop: the trigger that starts the share or invite, the incentive (intrinsic or extrinsic), how easy sharing is, the invite-to-activation conversion, and how often a user goes round the loop.
4. **Estimate the loop coefficient.**
   - K = shares or invites per user per cycle × conversion of those to activated users
   - New users per cycle = users completing the cycle × K
   - Cycle time = days for one turn of the loop

   K above 1 sustains itself; below 1 it still lowers blended CAC. Shorter cycles compound faster at the same K.
5. **Build one loop first.** Start with the most natural loop, tune its messaging and friction, measure its metrics weekly while optimizing, and layer secondary loops only once it runs. Viral loops compound fastest but take longest to build; collaboration loops give the strongest retention.

## Output

- All five loop types ranked for this product, with fit reasons
- The primary loop with its mechanics, trigger, incentive and implementation plan
- Secondary loops to layer later
- Loop health metrics: shares per user, invite conversion, K, cycle time
- A 30-60-90 day implementation roadmap
- Projected K and growth, with the assumptions behind them
